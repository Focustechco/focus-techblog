# blogfocus

PROMPT – BLOG FOCUS TECNOLOGIA (ESTILO TECH FUTURISTA)

Crie um blog moderno, interativo e visualmente impactante para uma startup chamada Focus Tecnologia, com identidade visual preta e laranja (#FF6B00), seguindo um estilo tech futurista inspirado no X (Twitter), com elementos espaciais e animações suaves.

🎨 ESTÉTICA & VISUAL

 Background animado com:

 Starfield (estrelas caindo lentamente)

 Partículas (poeira branca e laranja em movimento)

 Nebulosidade dinâmica (efeito leve, fluido)

 Adicionar scanlines sutis (efeito monitor retrô futurista)

 Paleta:

 Preto profundo (#000000 / #0A0A0A)

 Laranja destaque (#FF6B00)

 Branco para contraste

 Tipografia:

 Títulos: Bebas Neue

 Corpo: Rajdhani

 Labels/código: Space Mono

 Aplicar glow laranja suave em elementos interativos

 Bordas finas com destaque em hover (laranja)

🧱 ESTRUTURA DO BLOG

🔝 Navbar (sticky)

 Logo Focus Tecnologia

 Links de categorias (Tecnologia, IA, Startups, Marketing, Automação, etc.)

 Campo de busca funcional

 Efeito blur + transparência ao rolar

📊 Barra de Status (logo abaixo da navbar)

Exibir:

 Número de artigos

 Leitores ativos

 Autores

 Uptime do sistema
(estilo dashboard minimalista com ícones e animação leve)

🔥 Ticker de Trending Topics

 Barra horizontal com rolagem infinita

 Exibir hashtags e temas populares

 Movimento contínuo (loop suave)

🌟 Post em Destaque (Hero Section)

 Card grande com:

 Canvas animado (grid laranja + partículas)

 Título impactante

 Subtítulo

 Botão "Ler mais"

 Usar como case principal: Conlibras

 Animação leve no hover (zoom + brilho)

📰 Feed de Artigos

 Layout em cards

 Cada card deve conter:

 Número do post (#01, #02…)

 Título

 Categoria (tag)

 Pequeno resumo (excerpt)

 Hover com:

 Borda laranja

 Leve elevação

 Filtros por categoria (funcionais)

📌 Sidebar (lateral direita)

1. Trending Topics

 Lista dos assuntos mais acessados

2. Autores

 Avatar + nome

 Botão "Seguir" com toggle (seguir/seguindo)

3. Newsletter

 Campo de e-mail

 Botão de inscrição
